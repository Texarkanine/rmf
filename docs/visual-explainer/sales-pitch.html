Ad intake

You paste the ads. We do not invent a top five.

  • One Meta Ad Library link required. More optional.
  • Each creative is graded. Shared pages are walked once.
  • Video is frames plus copy — start, ~3s, ~8s, last — not a movie watch.
  • Audio transcription and scene-as-movie analysis are out of this ship.
Meta
only live ad path

Consumer journey

One shopper path. Then we stop.

  • Destination is whatever the ad opened — home, LP, or PDP.
  • Then product if needed, add to cart, cart, checkout page load only.
  • No email, address, phone, or card. Do not invent a card.
  • Account walls at checkout are in. Login walls before cart are out.

Walker does not judge

Playwright records

  • Pages, frames, copy, artifacts. No scores.
  • An AI helper that only finds a button is not a judge.
  • Reaching a thank-you page is a capture failure.

Grok works from the bundle

The only fact base

  • Findings must cite artifacts that exist.
  • Do not invent pages, CTAs, or errors never seen.
  • The scoring model pin is grading policy, not a default.
