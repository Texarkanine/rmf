3 — Stop

Stop before payment. Checkout showed card chrome and a disabled Pay now button. Email, name, address, phone, and card fields were empty. The walker has no .fill( / .type( calls. PAYMENT_SUBMIT refuses “Pay now” / “Place order”. A thank-you page or /paid URL would have failed the run.
  • Card fields sat in the main Shopify checkout document (form label “Credit card”), not in js.stripe.com / checkout.shopify.com iframes.
  • We did not type email to “reveal” more payment UI. The card placeholders were already visible on page load.
  • Tonal robots.txt disallows crawling /checkout and /checkouts/. This run is a shopper click-through with a cart cookie, not a crawler of those paths, and it does not complete payment.
